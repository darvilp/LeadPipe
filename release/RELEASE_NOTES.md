# LeadPipe 5.6.0.25

- Use LeadPipe names for the release tag and APK downloads.
- Prepare the updater for the repository rename. It looks up releases by GitHub repository ID and reads the release and APK URLs returned by GitHub.

The PipePipe base is v5.6.0 at client commit `43ef494c1`. This release uses the existing application ID, signing certificate and Room schema 903 for in-place upgrades.

If you are on `5.6.0.24`, use **Settings → Updates → Check for updates**. If you are on `5.6.0-unofficial.23` or older, download the appropriate APK from this release and install it over your existing app.
